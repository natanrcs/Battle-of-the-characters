# Heros Adventures

A small Python project built around object-oriented programming (OOP), where heroes and villains fight in turn-based battles.

## Purpose

The main focus of this project is to **practice coding and programming logic**. It is a learning playground, not a production game: the goal is to get comfortable with writing clean code, modeling problems with classes and thinking through edge cases.

## What it covers

- Classes, attributes and methods (`Character`)
- Properties (`is_alive`)
- Input validation and error handling with `ValueError`
- Control flow with conditionals and `while` loops
- Simulating battles between characters

## Running

```bash
python3 main.py
```
